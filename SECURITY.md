# Security Policy – Start Force One

Start Force One (`com.startforce.one`) is an Android app for sprint-start analysis and two-phone finish timing.
All recordings and results stay on the device; the only server contact is Google Play for the optional Pro purchase.

## Reporting a vulnerability

Please report security issues **by e-mail** to **startforceone@protonmail.com** (German or English).
Please do not open a public issue for security reports.

What helps us:

- the app version (Menu → Help → About) and the Android version,
- steps to reproduce, and what an attacker could gain,
- if the issue concerns the two-phone transfer: the network setup (Wi-Fi Direct or shared WLAN, pairing code on/off).

You will receive an acknowledgement within **7 days**. We aim to fix confirmed issues in the next app release and will
keep you informed. We will credit you in the release notes if you wish.

Machine-readable contact (RFC 9116): <https://knickl.github.io/startforce-legal/.well-known/security.txt>

## Scope

- the app itself (data handling on the device, the two-phone transfer, the optional ESP32 light-barrier link),
- this website (legal texts).

Out of scope: Google Play, Google's billing infrastructure, and the user's own Wi-Fi network.

## Supported versions

Only the current release on Google Play receives security fixes.

# Sicherheitsrichtlinie – Start Force One (Deutsch)

Sicherheitslücken bitte **per E-Mail** an **startforceone@protonmail.com** melden (Deutsch oder Englisch), nicht als
öffentliches Issue. Hilfreich sind App-Version (Menü → Help → About), Android-Version, Schritte zum Nachstellen und, bei der
Zwei-Handy-Übertragung, der Netzaufbau (Wi-Fi Direct oder gemeinsames WLAN, Pairing-Code an/aus).

Eingangsbestätigung innerhalb von **7 Tagen**; bestätigte Lücken werden mit dem nächsten App-Release behoben. Maschinenlesbarer
Kontakt: <https://knickl.github.io/startforce-legal/.well-known/security.txt>. Sicherheitsfixes gibt es nur für die aktuelle
Version auf Google Play.
